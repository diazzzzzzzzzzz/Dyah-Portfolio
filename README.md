# 🌐 Dyah's Portfolio

A personal portfolio website showcasing my background, experiences, achievements, projects, and technical interests.

🔗 **Live Website:** [Dyah's Portfolio](https://diazzzzzzzzzzz.github.io/Dyah-Portfolio/)

## 🛠️ Built With

* **HTML** — website structure and semantic content
* **CSS** — styling, layout, and responsive design
* **JavaScript** — interactions and dynamic behavior
* **Git & GitHub** — version control and deployment

## ✨ Features

* Responsive design for different screen sizes
* Interactive navigation
* About section with tab-based content
* Skills and experience sections
* Education and activities
* Project showcase
* Achievement and certification sections
* Interactive project details
* Contact section

## 📁 Project Structure

```text
Dyah-Portfolio/

├── images/
├── projects/
├── index.html
├── style.css
├── modal.js
└── .gitignore
```

## 🚀 Getting Started

Clone the repository:

```bash
git clone https://github.com/diazzzzzzzzzzz/Dyah-Portfolio.git
```

Open the project folder:

```bash
cd Dyah-Portfolio
```

Then open `index.html` in your browser.
